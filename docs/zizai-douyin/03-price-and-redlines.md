## 二、五条真红线（A 级，官方原文）

### 红线在本号的实操翻译

- **赌博样态**：不拍输赢结算、现金 / 筹码特写，不做输赢叙事，不做技巧教学，不用赌博框架组织站外导流；纯环境、设施、价格、组局氛围（无输赢、无结算）不在字面禁止内——但没有任何官方文件为「棋牌室宣传」开口子，所以按最严口径执行。
- **价格欺诈**：39.9 / 42.68 是叠加秒杀价，作为主价展示且不明示叠加条件，正中价格欺诈的「价格附加条件不标示或含糊标示」一类。历史上把内部备注「注意，叠加秒杀后的价格是…」原样发进公开文案的作品，属同类问题，已全部清理（见《04》《06》）。
- **锚点**：因为红线 3，「团购链接到底挂没挂上」不只是转化问题，是合规必查项，必须在 App 内实查确认。
- **AI 标识**：今后任何 AI 填充镜头进成片，发布时主动声明，不依赖平台代加。

## 三、自家从严禁用词（定性纠正）

- 现行自家禁用词表：赢钱 / 回本 / 稳赚 / 赌 / 包赢 / 手气旺 / 爽到飞起——这是**自家从严红线，不是官方词表**，继续执行，但定性必须说清。
- 核查结论：「手气」「爽」二词不出现在《抖音社区自律公约》全文中（已全文检索）；公约的操作性表述是「赌博样态」「赌博设备、器具」「赌博技巧」，没有官方禁用词表把「手气旺」「爽到飞起」列名。
- 其中「赢钱 / 稳赚」类收益承诺另有真实官方钩子：公约虚假宣传 / 夸大收益条款与生活服务虚假宣传规则——依据不同，不要混为一谈。
- 同理纠正：**无关 / 跨城标签不是违规**，只是效果问题（数据见《04》）；存量模板卡不带合规风险，处置按效果与口径分类，不按违规分类。

## 四、三个悬案的定级结论（2026-11-09 核查）

1. **已发布作品的文案 / 标签能否修改**：功能存在为 **B 级**（多个二手来源一致）；网传参数（每日一次、仅 30 天内、2025-10 上线）为 **C 级**，未找到官方文本。它不影响删除类处置：目标作品都已超过任何传闻中的可改期。
2. **删除作品的后果**：不可恢复为 **A 级**（《抖音用户服务协议》：对已删除的用户信息或内容，平台有权不予恢复）；总获赞随删除作品扣减为 **A− 级**。「权重」不是抖音的官方概念；「删作品限流 X 天」「批量删除有阈值」均为民间说法且数字互相矛盾，**C 级**，不作决策依据。
3. **棋牌类目的审核细则**：**C 级——官方从未公开发布**棋牌类目归属细则或涉赌认定标准。网传「麻将直播指南」类文章无官方出处，不可引用。可依据的只有公约赌博样态条款（A 级）与执法口径（B 级：官方反赌博执法公告经多家媒体转载一致，其中提及 2026 年内赌博导流账号日均封禁超 1 万）。
