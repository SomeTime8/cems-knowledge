# 视频制作规格（时长 / 卡点 / 钩子）

> 本规格是后续所有短视频的剪辑依据，执行员拿着就能剪。证据分级：**A** = 自家全量数据 / 本地实测；**B** = 期刊实证研究（注明样本边界）；**C** = 行业机构 / 厂商 / 聚合数据；**D** = 行业经验与教程共识（无量化实证）。每条规格回指级别，不混写。

## 一、时长分档（按题材）

| 题材档 | 总时长 | 镜头数 | 单镜时长 | 定位 |
|---|---|---|---|---|
| 环境种草 · 沉浸式（一镜到底推门、扫码开门、升牌） | **12–18s** | 3–4 镜 | 2.5–5s（按小节取整） | 主力氛围片 |
| 环境种草 · 答疑型（四问：时间 / 卫生 / 烟味 / 组局） | **18–26s** | 4–5 镜 | 3–6s | 答疑内容档 |
| 组局召集（三缺一、报到帖） | **15–22s**；定番短帖版 **12–15s** | 3–5 镜 | 3–5s | 周四 / 周五晚档发 |
| 价格锚点（看空房、套餐展示） | **15–22s** | 4 镜 | 3–6s + 尾卡 | 价格只进尾卡 |
| 功能演示（计分工具、组局录屏） | **20–28s** | 4–5 镜 | 4–7s（录屏镜可到 7s） | 演示完整性优先于短 |
| 信任 / 口碑（顾客原话、被认可） | **18–25s** | 4 镜 | 4–6s | 情感线，不追快剪 |
| 卡点快剪（照片转视频、开门特写组） | **8–15s** | 6–12 镜 | 每 1–2 拍一镜（0.5–1.25s） | 只用于氛围 / 特写组，不承载讲解 |

**硬边界（全题材通用）**：

- 默认上限 **30s**，绝对上限 **35s**：超过后完播与转化双降（B 级证据：转化峰值区间 15–35s、>45s 显著下降；本号无投流、自然流为主，再从严一档）。
- 下限 **12s**：<10s 的电商视频转化显著下降（B）；8s 以下只许卡点快剪档使用，且不作主力格式。**7 秒级只可作钩子 / 氛围试验片，不作常规档。**
- 切镜速率：讲解型 0.2–0.4 次 / 秒（单镜 2.5–5s）；快剪档 0.8–1.6 次 / 秒。期刊给电商带货的建议是 0.8–1.2 次 / 秒（B），那是强卖点带货片的节奏；本号是到店服务、沉浸与信任优先，只在快剪档采用，讲解档降档执行——这是有意的本地化，不是不达标。

## 二、结构与钩子（每条片固定骨架）

- **0–1s**：第一帧必须是「信息帧」——门头全景、扫码动作、升牌瞬间、包间全景四选一；禁黑屏、禁淡入、禁 logo 开场。钩子字幕在 **0.3–1.0s 内上屏**。
- **0–3s 钩子**：钩子句必须在 3 秒内说完 / 显示完（口播 ≤13 字）。句式只用四类（本地化版）：
  1. **问题直问**：「几点关门？」「包间里有没有烟味？」（顾客四问本身就是钩子库）
  2. **反常识翻转**：「不关门。」先问后翻，或直接把反常识结论放第一句
  3. **动作 / 结果前置**：先给扫码开门、灯亮、升牌的完成瞬间，再回头交代——前 3 秒出现核心场景特写的视频，后续完播高 35%（B，电商样本）
  4. **身份点名**：「汝城打麻将的，看一下这间包间」——点名只许点汝城本地，禁跨城喊话
- **中段**：每 5–7 秒必须有一个新信息点（新场景 / 新卖点 / 新状态），不许一个镜头闲置超过 6 秒；信息点尽量落在 25% / 50% / 75% 位置（D）。
- **结尾**：提问式结尾 → 尾卡。尾卡停留 **2.5–3.5s**（价格尾卡可到 4s 封顶），内容 = 店名 · 郴义路 + 本条价格口径一行 + 导航 / 小程序指引；尾卡是定帧，不配口播。

## 三、卡点规则（BGM 先行，镜头服从拍网格）

1. **先选 BGM、后排镜头**：合成第一步永远是定 BGM 并测出 BPM 与拍点相位，再把镜头长度量化到拍网格上。禁止先剪画面后铺音乐。
2. **拍网格公式**：一拍时长 = 60 ÷ BPM 秒；4/4 拍一小节 = 4 拍。镜头时长只许取 **整小节**（沉浸 / 讲解档）或 **整拍 / 半小节**（快剪档）。常用对照：

   | BPM | 一拍 | 一小节（4 拍） | 适用档 |
   |---|---|---|---|
   | 96 | 0.625s | 2.50s | 沉浸式环境 |
   | 100–110 | 0.55–0.60s | 2.18–2.40s | 环境 / 组局 |
   | 120 | 0.50s | 2.00s | 价格锚点 / 快剪入门 |
   | 128–140 | 0.43–0.47s | 1.71–1.88s | 卡点快剪 |

   BPM 选曲区间（D 级经验）：沉浸环境 85–105、组局 / 价格 100–120、快剪 120–140；只选鼓点清晰、节拍稳定的曲子，曲目进 BGM 安全库时登记 BPM。
3. **切点对齐**：场景级硬切 / 叠化中心必须落在**小节线**上（误差 ≤±0.05s）；字幕弹出、关键词放大落在**拍点**上（误差 ≤±0.08s）；叠化时长 0.2–0.3s 且以拍点为中心对称。一条片只需卡准 3–5 个关键点（钩子落点、每次场景切换、尾卡入场），不必每拍都切（D）。
4. **相位先行**：BGM 截取段的第一个强拍不一定在 0.00s——先测截取段的起始拍相位偏移，把整张拍网格平移对齐后再排切点。本地实测案例：现用曲目《Carefree》标注 96 BPM、实测 95.7（误差 <0.5），其截取段强起拍约在 0.31s 处，相位不在零点。
5. **配音片的卡点**：有口播时不追求切点卡拍，改为「**口播句读卡小节**」——每句口播的起句落在小节线上，句间留 0.2–0.4s 气口；BGM 音量压到 −28dB 左右垫底（已交付片实测值），不与人声抢拍。

> **卡点的证据定性（必须如实保留）**：在本次检索范围内，**没有任何官方 / 期刊 / 数据机构发布过「卡点 vs 不卡点」的完播对照实证**；市面「卡点提升完播 X%」的说法均无样本、无方法，不采信。卡点在本规格中定为 D 级经验 + 弱间接证据：低成本、零风险，值得执行，但必须靠自家 A/B 验证（见第六节），不能当作已证实的流量杠杆宣传。

## 四、字幕与语速

- 口播语速：设计目标 **3.5–4.5 字 / 秒**，硬上限 5.5 字 / 秒（期刊对电商口播的建议是 3–4 字 / 秒，B——本号取 3.5–4.5 为设计带、上限不动）。
- 画面字幕：单行 ≤12 字、同时 ≤2 行；字幕上屏时机与口播同步，关键词（价格、24 小时、扫码开门）可单独放大一拍；字幕停留 ≥1.2s 才许消失。
- 标题正文纪律不在本规格重复立规，见《03》《04》：正文 ≤10 字最佳、价格不进标题、标签 100% 相关。

## 五、封面帧

- 从**前 3 秒内**的画面里选：优先门头全景（带招牌字）或升牌 / 开门完成瞬间；必须是实景帧，禁模板卡图、禁带烧录价格字的原图裁切。
- 封面大字 ≤8 字（就是钩子句），以手机列表尺寸下可读为准；选帧后导出静帧自检一次。

## 六、证据基础与验证设计

- **最硬的外部证据**：程柯、赵盼盼《电子商务评论》2025, 14(10)（DOI: 10.12677/ecl.2025.14103355），抖音 12,850 条电商视频实证——转化率呈倒 U 型、峰值在 15–35s，<10s 与 >45s 显著下降；特征重要性 Top 5 为产品首现时间、标题促销词、语速、切镜速率、产品时长占比，粉丝数弱相关；转引研究含「前 3 秒产品特写 → 后续完播 +35%」。**样本边界必须注明**：样本是 2023 年电商带货视频，不是本地生活到店，所以本规格取其区间、不取点位，并结合自家数据再从严。
- **自家证据（A）**：形态与标签结论来自 92 条全量盘点（见《04》）；拍点参数来自本地实测（解码 + 频谱通量起始点检测）。
- **数据缺口**：自家 92 条归档没有时长字段，「时长—播放」对照不存在；竞品单条时长网页端不可见。此两项为空缺，不编造。
- **最小验证设计（待执行）**：① 新片逐条登记时长，先补上数据地基；② 同素材双剪对照（卡点对齐版 vs 不对齐版）比完播与中位数，判定阈值预先定死（如对齐版中位数高出 ≥30% 才升级为自家结论）；③ 同题材双时长版对照；④ 尾卡时长交替试验。验证结果回写本条目。

## 七、存量片评级（按本规格，2026-11-09）

| 片子 | 评级 | 依据与处置 |
|---|---|---|
| 7 秒推门片（一镜到底试验片） | **需重剪（小改）** | 第一切点恰压小节线合格，第二切点未锁拍、后两段非拍长整数倍，后半段脱离拍网格。改法：重排 2.50 / 2.50 / 2.50 = 7.5s 并按相位对齐；另出一条 15 秒正档版作正式发布 |
| 27 秒「四小时 45.9」 | **合格** | 27.0s 正落在 15–35s 峰值区间，6 镜单镜均 4.5s 在讲解档速率内；可选优化仅两项（首帧换完成帧；重剪可压到 22–24s），不插队 |
| 四周内容包 12 条 | 逐条修订清单已出 | 主要问题：尾卡原定 4–5s 系统性偏长（统一削到 2.5–3.5s）；2 条时长超档需压缩；1 条名为快剪实为单镜长镜头，需按快剪档重构为多镜 + 尾卡。清单只记录，未改动原内容包文件，落改另行安排 |

## 八、BGM 版权口径

- 只用免版税安全库曲目，不扒平台热门视频原声、不用来源不明的曲子；选曲时登记 BPM 与授权类型。
- 现用曲目：《Carefree》— Kevin MacLeod，CC BY 4.0（可商用，条件是发布时在视频描述中署名）；发布文案带署名行，或在 App 内改挂平台曲库音乐则免署名。
- 音量口径：无口播片 BGM 为唯一声音时仍压低做垫乐；有口播时约 −28dB 垫底，结尾淡出。
