# 自动代发事件复盘

> 事件：2026-11-09 凌晨 04:00，账号在无人操作的情况下自动发布了一条模板视频。调查结论（高度疑似）：发布源是抖音来客「智能创作」的 AI 自动投稿 / 托管。本条目记录识别方法、证据链与关停经验，供任何本地生活商家号排查同类问题时复用。

## 一、事件经过

- 09:08 例行盯盘发现当日 04:00 新发一条视频：长卖点文案、随机不相关与跨城标签，0 播放；其余账号数据无变化。账号所有者确认：**是自动代发的**，非人工发布。
- 该条经明确指示后删除（删前以发布时间、标题开头、播放量三项核对无误）：公开作品 82 → 81，置顶与最高播放作品在位，粉丝、获赞不变。
- 同日完成来源调查；账号所有者本人在商家 App 内关闭自动投稿开关（约 10:22），并开启 48 小时验证窗（见第五节）。

## 二、来源结论：来客「智能创作」AI 自动投稿 / 托管

**定级：高度疑似（接近确认）**。机制与本账号全部特征逐项吻合（公开教程多源互证，含抖音官方账号发布的智能创作教学）：

| 特征 | 本账号实测 | 该机制的公开描述 |
|---|---|---|
| 账号类型 | 商家认证账号 | 智能创作仅对入驻商家开放 |
| 成片形态 | 门店照片拼图模板、图文与短视频混发 | 用商家上传的门店素材 + 团购商品自动成片 |
| 文案 | 长卖点文案、「4.2 / 4.3 分推荐」话术；甚至把内部备注原样写进公开文案 | AI 按商家填写的商品卖点自动写文案 |
| 标签 | 每条随机挂与门店无关的话题，含跨城地名 | 系统自动填充「推荐话题」 |
| 团购导向 | 文案反复喊「点击左下角享优惠团购」 | 成片自动挂载 POI 与团购链接 |
| 发布时间 | 全天候随机分布（见第三节） | 系统选择「合适的时间」自动发布 |
| 持续性 | 2026-04 起持续出现，近期加密至一天 1–2 条 | 托管模式持续自动投稿，直到在商家端关闭 |

**价格注释之谜同源解开**：历史作品里反复出现的内部备注原文（「注意，叠加秒杀后的价格是 39.9 元，团购价是 45.9 元；」），是商家在填商品卖点时把内部备注一起填了进去，AI 照单全收写进公开发文案——这也是全号「价格注释原文公开」风险类的成因（处置见《04》）。

**无法从网页端确证的部分**：开关的当前状态只在商家 App 内可见；创作者中心与抖音网页版均无此入口。第三方批量发布工具无法 100% 排除，但全部可见特征可由该单一机制解释，且账号所有者本人亦确认「平台自动发的」。若在 App 内发现开关本是关着的，再回头查第三方授权。

## 三、排查证据链（本次逐项核查结果）

1. **创作者中心定时 / 预约队列：排除。** 作品状态筛选只有全部 / 已发布 / 审核中 / 未通过，「审核中」「未通过」均为 0 条，无任何待发队列；被删那条的编辑页是标准发布表单，无来源、无定
...[truncated 3533 chars]时字段。
2. **网页端授权 / 自动发布开关：不存在。** 创作者中心无授权入口，抖音网页版无设置与授权管理入口——授权管理只在 App 端（设置 → 账号与安全 → 授权管理）。
3. **发布时间规律：系统择时，不是人工定时。** 实测提取 108 条发布时间戳：凌晨 01:01–06:48、深夜 23:20–23:54 均有分布，分钟随机，无任何整点 / 固定时点规律。
4. **43 条差额已区分。** 创作者中心总数 = 公开作品 + 43 条私密作品；私密区全是同模板卡且带 5–39 播放量——是曾公开发布后转私密，**不是草稿、不是待发队列**（是谁 / 何机制转的私密，网页端无法确证；另有商家教程提到该托管自动发的视频「会莫名其妙消失」，形态一致）。

## 四、关停方法（经验条目）

- **主路径（商家 App 内操作，网页端关不了）**：抖音来客 App → 全部服务 → 智能创作 → 右上角「投稿设置」→ 选择对应门店 → 关闭「抖音主页视频展示」与「图文」两个投稿开关 → 确定；若另有「AI 自动投稿 / 托管」总开关，一并关闭。出处为抖音站内商家实录教程；本账号已按此路径关停。
- **兜底排查**：抖音 App → 设置 → 账号与安全 → 授权管理，逐项排查并解除不认识的第三方授权。
- **影响评估（关停前最担心的，先查清再关）**：关投稿开关**不影响团购**——POI、团购商品、在售套餐、核销都在商家商品体系里，与投稿是两套东西；存量作品也不会被动变化。关停后失去的只是「零人力持续更新」，而这批自动内容正是数据认定的负资产（见《04》）。
- **注意**：源头没关之前，新自动作品随时可能再出现；「队列里没有存量」不等于「源头已停」。

## 五、验证窗口与盯盘口径

- 关停后设 **48 小时验证窗**（本例：2026-11-09 约 10:22 至 11-11 约 10:22）：窗口内每日盯盘专门核查有无新的疑似自动代发作品；无新作出现，即判定关停确认；若再现，先上报账号所有者、不自行处置，并转入兜底排查（授权管理）。
- 日常判别口径：新作品若呈「长卖点文案 + 随机不相关 / 跨城标签 + 非人工时点发布」三件套，优先按疑似自动代发上报，与人工发布、运营发布三者分开记账。
