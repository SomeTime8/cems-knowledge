## 关键结论速览（实测）

- **账号底盘**（2026-11-09 删后快照）：粉丝 30、获赞 179、公开作品 80；全号最高播放 3,587（「#附近麻将团购」），置顶三条 2855 / 1113 / 691。
- **流量结构**：92 条作品总播放 27,455，中位数仅 18；20 条破百作品拿走 95.3% 的播放。视频 30 条中位数 446、破百率 56.7%；图文 62 条中位数 16、破百率 4.8%。
- **转折点**：2025-12 至 2026-03 的 22 条里 19 条破百；2026-04 弃视频、转模板图文后，70 条仅 1 条破百。
- **最强变量是标签相关性**：标签 100% 与汝城 / 麻将 / 棋牌 / 同城相关的 16 条全部破百（中位数 1,015）；无关标签占多数的 68 条中位数 11。
- **价格口径（唯一对外口径）**：4 小时麻将团购价 45.9 元（原价 60）；大包 + 自助茶水 49.9 元（原价 100）；随时退、过期退。秒杀叠加价 39.9 / 42.68 不是团购价，永不作主价。
- **风险治理**：历史风险作品已清理完毕——禁用词与价格注释类共删除 12 条（11 条 + #23），「价格注释原文公开」风险类清零；被平台商家工具自动代发的源头（来客「智能创作」托管）已关停。
- **打法主线**：停发模板卡 → 回归实拍短视频 + 全相关标签 + 短标题 → 把流量承接到组局与团购；30 天目标为测算：新片中位数 ≥100、破百率 ≥40%、评论咨询从 0 到 ≥3 条。

## 运营纪律（现行）

- **实拍原则**：门店视频必须用门店真实素材；AI 生成画面只作结构示意或通用填充，不冒充门店实景；使用 AI 生成内容发布时按平台规则主动标识。
- **发布前检查**：文案先过禁用词与价格口径扫描——价格只进尾卡、正文不写价格、标签 100% 相关、正文尽量 ≤10 字。
- **删除原则**：平台删除不可恢复（官方口径 A 级），每次删除前以日期 + 形式 + 播放量三项核对目标，删后复核作品总数与受保护作品在位情况，并逐条记账。
- **证据分级**：引用平台规则时分 A（官方原文）/ B（多源一致的二手来源）/ C（未核实）；C 级只作风险提示，不作行动依据。

## 续写约定

## 关键结论速览

- **账号基线（2026-11-09 收盘）**：粉丝 30、获赞 179、公开作品 80；单条最高播放 3,587；顾客咨询评论 0 条（待建渠道）。
- **形态结论**：92 条实测——视频中位数 446、破百率 56.7%；图文（模板卡）中位数 16、衰减至个位数。停模板卡、回视频是第一杠杆。
- **标签结论**：标签 100% 相关的作品全部破百（中位数 1,015）；无关标签是效果杀手。今后只准地域 / 品类 / 入口三类标签。
- **价格口径**：4 小时麻将团购价 45.9（原价 60）、大包 + 自助茶水 49.9（原价 100）；秒杀叠加价 39.9 / 42.68 不是团购价，禁止作主价；价格只进尾卡、不进正文。
- **红线**：赌博样态、价格欺诈、无锚点硬广、AI 内容未标识、账号出借与自动化——五条 A 级红线，全文见《03》。
- **已作废**：「评价返时长」因平台操纵评价治理作废，替代口径为邀评不挂利益、福利改挂打卡礼（见《07》第六节）。

## 运营纪律（现行）

1. 店内视频用门店真实素材；AI 画面只作结构演示或通用填充，不冒充实景。
2. 删除等不可逆处置前逐条逐字复核原文，不按二手归类下手。
3. 新发作品 100% 视频、100% 相关标签、价格只进尾卡；每条发布前过《03》的检查清单。
4. 代运营动作逐条记账（内容 / 时间 / 结果 / 依据），周一时报对账；真实花钱先报批。
5. 平台规则类结论标注证据等级（A 官方原文 / B 多源二手 / C 未核实），不把传闻写成规则。
