# CEMS 2.0 项目推进操作手册

> [下载 PDF 版（13 页 A4，可打印填写）](./CEMS%202.0%20项目推进操作手册.pdf)

> 配套 15 号《开发改进计划》的落地操作文档：你要做的只有三件事——拍板、验收、踩刹车。
> 时间：2026-10-19（2026-10-19 增补：Docker 部署方案、项目加速八法、待拍板清单已拍板）

## 内容一览

- **第一章 决策闸门 0**：地基三件有着落、仓库与唯一通道就绪、后端四项放行、每阶段有验收人——四项全勾才开工
- **第二章 第 1 周清单**：7 件现在就能做的动作，每件有产出物和负责方
- **第三章 Phase 0–6 操作卡**：每阶段一张卡——目标 / 你做什么 / 助理做什么 / 外部配合 / 产出物 / 过关标准（Phase 0 已增补 Docker 环境、代码生成器、API 契约、数据迁移调研、P0 安全五项前置任务）
- **新增 部署方案章**：Docker Compose 定案、四方案对比、混合架构表、四步迁移路径、一键部署脚本升级为 `docker compose pull && up -d`；TencentDB 列为备选、自建 MySQL 为默认
- **新增 项目加速八法**：模块化单体（不做微服务）、生成器提前到 Phase 0、API 契约先行、渐进式替换（绞杀者模式）、数据迁移 Phase 0 调研、特性开关、每周演示、P0 安全进 Phase 0
- **第四、五章 执行 SOP 与交付规范**：每个功能统一走 8 步；交付只走唯一通道（预发布 → 冒烟 → 切换 → 可回滚）
- **第六、七章 周节奏与分工**：周一排期、每天三行同步、周五验收
- **第八章 待拍板清单（已拍板）**：9 项 2026-10-19 已全部按默认通过——后端 Spring Boot 3.2+JDK17、MySQL 8.0、Phase 0+1 先行、同机部署、一键部署脚本采用、GitHub 历史重写暂缓、OCR 接入、补跑复查暂缓、三线并行；状态：已决策、未开工，等开工令
- **第九章 风险红线**：对外签章走持牌服务商、协同编辑先过法务、埋点先有告知制度、未上 HTTPS 不做离线应用等 6 条，触碰即停
- **附录**：启动清单、第一周派单表、阶段验收单、单功能验收单，打印就能填
