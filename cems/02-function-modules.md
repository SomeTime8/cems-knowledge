## 核心业务链（实测）

### 项目链：完整
项目列表 → 详情 → 预算（6 条，汇总 70,020,000）→ 甘特图（8 条）→ 阶段（8 条）→ 里程碑（7 条）→ 进度填报（5 条）→ 进度对比（8 条）→ 工程报告（3 条）→ 现场记录（媒体 3 条）→ 质量计划（4 条）/整改（3 条）/报表 → 安全检查（3 条）/整改（2 条）/报表 → 成本（14 条）→ 变更签证（0 条）→ 竣工（36 条）→ 保修（0 条）→ 归档

- 项目字段：id / name / code / type / scale / region / owner / manager / techLead / deputyManager / contractAmount / startDate / endDate / status / contractId / contractName
- 状态枚举：立项 / 筹备 / 在建 / 竣工 / 结算 / 归档；类型：市政 / 公路 / 房建 / 水利 / 机电 / 矿山；规模：大型 / 中型 / 小型

### 招投标 → 合同 → 财务链：基本可用
招标信息 1054 → 投标登记 5 → 资格预审 4 → 保证金 3 → 投标文件 4 → 开标提醒 5 → 中标结果 7（中标率统计接口可用）→ 合同 9 → 付款计划 3 → 履约保证金 4 → 付款申请 5 → 回款 5 → 发票 7

### 人事 → 证书 → 劳务链：基本可用
员工 2 → 合同/续签 → 考勤（打卡记录 18、补卡 1、班次 0）→ 请假 5 → 加班 1 → 出差 1 → 薪资档案 4 / 核算 2 / 社保 1 → 培训计划/记录各 1 → 招聘（岗位/候选/面试均为 0）→ 证书（人员 27、企业 6、提醒 19）→ 劳务（队伍/工人/合同各 1）

### 材料 → 设备 → 用印 → OA → 知识库：基本可用
材料、设备、用印、OA、知识库、消息、审批、系统管理均有页面与真实 API，多数列表可分页、搜索、筛选；部分子模块数据为 0（见 04）。

## 前端通用模式（实测自 View 源码）

- 列表页：`SearchForm`（搜索/筛选） + `DataTable`（分页） + `CrudDialog`（新建/编辑弹窗） + 统计卡
- 项目列表：搜索（名称/工程类型/项目规模/状态）+ 统计（total/building/finished/amount）+ 删除确认 + 提交审批
- 合同列表：OCR 导入（`contract-COX8eYRi.js` 调 OCR 提取合同名称/甲乙方/金额/日期）+ 付款计划/履约保证金/风险预警
- 备份页：`el-alert` 提示“每天凌晨 3 点自动备份” + 立即备份按钮（Mock，见 05）+ 表格（备份文件/时间/操作人/大小/类型/状态）
